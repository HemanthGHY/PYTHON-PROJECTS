# Multi Layer Perceptron From Scratch

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python train.py
```

## Project Structure

```
mlp_from_scratch/
│
├── activations.py
├── dataset.py
├── network.py
├── train.py
├── requirements.txt
└── README.md
```

This project implements:

- Forward Propagation
- Backpropagation
- Gradient Descent
- ReLU
- Sigmoid
- XOR Classification

No TensorFlow.
No PyTorch.

Only NumPy.
